Installation
=======================

.. rst-class:: lead

    Overview of monorepo installation.
----

Monorepo is only supported on Ubuntu 24.04. For Windows users, we recommend you configure a Linux dual-boot
setup, and for macOS, you must run Monorepo from a UTM virtual machine running Ubuntu 24.04.
